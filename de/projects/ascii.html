Bild → ASCII

Python-Konverter für ASCII-Art

Projektübersicht

Dieses Projekt ist ein in Python entwickelter Bild-zu-ASCII-Konverter. Jeder Pixel wird analysiert und abhängig von seiner Helligkeit einem Zeichen zugeordnet. Ziel ist es, beliebige Bilder in ASCII-Art umzuwandeln, die direkt in einem Terminal dargestellt werden kann.
