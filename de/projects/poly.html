Polymorphe Engines & PRNG

Experimentelle Studie einer polymorphen Engine für Pseudozufall

Einleitung

Ausgangspunkt war eine einfache Frage: Lässt sich das Verhalten einer polymorphen Engine — eines Systems, das seine Form kontinuierlich verändert und dennoch eine interne Logik behält — visualisieren und als Grundlage eines Pseudozufallsgenerators verwenden? Ziel war kein klassischer PRNG, sondern eine geometrische und organische Sicht auf „Entropie“.

1. Modell der polymorphen Engine

Zunächst wird das System als dynamisches Netzwerk dargestellt. Jeder Knoten steht für einen Punkt, jede Kante für eine Wechselwirkung. Der Graph verändert sich abhängig von den Eingabeparametern.

2. Verformbare Kugel

Anschließend wird das Netzwerk auf eine Kugel projiziert. Die Knoten liegen auf der Oberfläche und können sich leicht zum Zentrum hin oder davon weg bewegen. Dadurch entsteht geometrische Variabilität, die die erzeugten Zeichen beeinflusst.

3. Rotation

Eine kontinuierliche Rotation ergänzt eine zeitliche Dimension. Jeder Knoten folgt einer Bahn im Raum; dieser sich ändernde Zustand beeinflusst die Zeichenerzeugung.

4. Kombination beider Effekte

Verformung und Rotation werden kombiniert. Position, Geschwindigkeit, Richtung und Abstand der Knoten zum Zentrum bestimmen gemeinsam den nächsten Textwert.

5. Experimentelle Texterzeugung

Im letzten Experiment wird der momentane Zustand der Engine auf pseudozufälligen Text abgebildet. Das Ergebnis wird nicht als kryptografisch zufällig beansprucht, sondern entsteht aus der internen Dynamik des geometrischen Systems.

Fazit & Perspektiven

Das Projekt ermöglichte mir eine visuelle und intuitive Auseinandersetzung mit Pseudozufall. Derzeit betrachte ich die Engine eher als künstlerisch-experimentelles Modell denn als mathematisch validierte kryptografische Primitive. Offene Fragen betreffen unter anderem die Abbildung räumlicher Änderungen auf Zeichen, die Parametrisierung der Bewegungen und kontrollierte Sequenzen für definierte Ziele.
