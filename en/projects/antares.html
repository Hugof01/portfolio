Antares

Secure macOS encryption software

Overview

Antares is the most mature personal software project I have built so far. I have worked on it for almost a year with a straightforward objective: build a macOS encryption tool that is accessible, reliable and aligned with modern security practices.

I developed the whole application myself: interface, encryption layer, Secure Enclave and Touch ID integration, integrity checks, logging system and internal architecture.

The user flow remains intentionally simple: select a folder, choose an authentication method, then encrypt or decrypt. Behind this simple workflow is a complete structure dedicated to robustness, consistency and data verification.

Core features

  • Select a folder to encrypt or decrypt.
  • Password or Touch ID authentication through Secure Enclave.
  • Hardened key derivation with Argon2id.
  • AES-128 or AES-256 depending on the selected level.
  • Protected header containing IV, format version, level and integrity tag.
  • Automatic integrity verification before each operation.

Analysis & verification tools

A significant part of Antares focuses on the security surrounding encryption itself. A verification module analyzes encrypted files and reports suspicious changes.

  • Internal log viewer and log-integrity verification.
  • Mapping-file integrity verification.
  • Folder analysis with file-by-file checks.
  • Targeted decryption of a specific file.

Debug mode

Debug mode was designed to support testing and to make the software’s internal behavior easier to understand. It can inspect encrypted files, verify their integrity and force controlled decryption during development.

Settings & maintenance

  • Light/dark mode.
  • Reset the mapping file.
  • Clean orphan files.
  • Full log purge.
  • Six application languages.
