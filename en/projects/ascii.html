Image → ASCII

Python image-to-ASCII converter

Project overview

This project is an image-to-ASCII converter written in Python. It analyzes the pixels of an image and maps each one to a character according to its brightness. The objective is to transform any image into ASCII art that can be displayed directly in a terminal.
