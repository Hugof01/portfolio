VCG — Visual Cipher Grid

Personal research project continued as a final engineering project

General overview

VCG (Visual Cipher Grid) is an original symmetric-cipher research project built around a two-dimensional representation of data in a 26×26 grid. Instead of operating directly on message bytes, the textual mode encodes information into a matrix of bigram positions and then transforms that structure through secret row/column permutations and XOR masking with a random initialization vector.

The project later evolved toward full-color document processing through 26×26 tiles and a chaining mechanism inspired by CBC. Its security properties were explored through formalized statistical experiments, including the Shannon-style experiment described below.

Fundamental grid principle

The central structure is a binary 26×26 grid whose rows and columns are indexed by the Latin alphabet. Each cell corresponds to an ordered pair of letters, giving 26² = 676 possible bigrams.

Text is rendered with 4×5 bitmap patterns placed into the grid. The resulting plaintext grid P is a canonical visual representation of the message before permutation and masking.

Secret-key structure

The secret key contains two independent permutations of the 26-letter alphabet: one for columns and one for rows.

K = (Kc, Kr)   with   Kc, Kr ∈ S26
|K| = (26!)² ≈ 1.61 × 1053

The permutation preserves the number of active cells but changes their positions. Decryption applies the inverse row and column permutations.

Secret permutation operator PS

PS(G)i,j = GKr(i), Kc(j)
PS−1(PS(G)) = G
  • Value preservation: only positions change.
  • Exact reversibility: the correct key reconstructs the original grid.
  • Bijection: PS maps grids one-to-one.

Encryption versions

VersionEncryptionDecryptionMechanism
V1C = PS(P)P = PS⁻¹(C)Permutation only
V2C = PS(IV ⊕ P)P = PS⁻¹(C) ⊕ IVXOR + permutation
V3C = PS(IV ⊕ PS(P))P = PS⁻¹(PS⁻¹(C) ⊕ IV)Double permutation + masking

V3 is the main version. The sequence PS → XOR → PS places the random mask between two secret permutations. V1 and V2 were retained as development stages but not as the main design because their statistical resistance was weaker.

Text-encryption pipeline

  1. Read plaintext.
  2. Encode characters as 4×5 bitmap patterns.
  3. Place patterns in the 26×26 grid.
  4. Build the active-bigram plaintext grid P.
  5. Generate a random IV with Bernoulli p = 0.5.
  6. Apply the first secret permutation PS(P).
  7. XOR the permuted grid with the IV.
  8. Apply the final secret permutation.
  9. Serialize the active positions and transmit/store (C, IV).

Decryption runs the inverse pipeline. The order in which active bigrams are serialized does not affect reconstruction of the grid.

Color documents and images

VCG was extended to raster images and PDF documents. Pages are converted to RGB, padded to multiples of 26 pixels and split into 26×26×3 tiles. V3 is applied independently to each color component.

C₁ = PS(P)
Y = mask ⊕ C₁
C = PS(Y)

A CBC-inspired chaining mechanism makes the mask of a tile depend on previous encrypted state so that identical plaintext tiles do not systematically produce identical encrypted tiles. Encrypted pages are stored losslessly as PNG data inside a .cgrid archive.

Data expansion: rasterization makes encrypted document size grow significantly. For PDFs, the prototype’s cost grows approximately as O(DPI²); lower DPI values are therefore much more practical for large documents.

Statistical tests

Large test campaigns were performed to study whether the visual structure of plaintext grids remains detectable after V3. Metrics include cell-activation distributions, mean, standard deviation, coefficient of variation, empirical entropy, heatmaps and histograms.

0.2929mean activation — plaintext P₀
0.4957mean activation — encrypted P₁
0.1059std. dev. — plaintext
0.0052std. dev. — encrypted

On the documented 10,000-grid experiment, the χ² statistic for encrypted grids was 189.73, below the stated 99% critical threshold of 763.40 for 675 degrees of freedom, with a reported p-value of 1.000.

Security analysis & Shannon experiment

Exact reversibility follows from the bijectivity of PS and the involutive property of XOR:

PS⁻¹(PS⁻¹(C) ⊕ IV) = P

The project also evaluates pseudo-brute-force behavior by decrypting an intercepted (C, IV) pair with many random pseudo-keys and analyzing the resulting pseudo-plaintext distributions.

For the implemented Shannon-style experiment, 10,000 natural plaintext grids (P₀) are compared with 10,000 pseudo-plaintexts (P₁) reconstructed using random permutations. Within the statistical model studied, the project reports the two distributions as statistically indistinguishable under the implemented χ² test and describes V3 as statistically IND-CPA against this frequency-based experiment.

Comparison with standard algorithms

Performance experiments compare VCG with AES-128-CBC, AES-256-CBC and ChaCha20-Poly1305. The comparison is not like-for-like: AES and ChaCha20 operate on raw bytes whereas VCG includes rasterization, tiling and grid transformation.

AES and ChaCha20-Poly1305 are much faster in the current measurements. The Python VCG implementation also creates substantial size expansion for rasterized PDFs. Low-level implementation, parallelization and pipeline optimization are identified as future work.

DPI impact

DPI is the main quality/performance control in the document pipeline. Higher DPI creates more pixels and therefore more 26×26 tiles; the computational and storage costs grow roughly with DPI².

Conclusion

VCG explores a visual approach to symmetric encryption based on bigram grids, secret row/column permutations and random XOR masking. V3 combines two permutations around the masking step, and the project extends the concept to full-color documents through tiled processing and CBC-inspired chaining.

The current implementation is experimental research software. Identified next steps include a lower-level C/C++ implementation, parallel processing, rasterization optimization and an integrated authentication mechanism for ciphertext integrity.
