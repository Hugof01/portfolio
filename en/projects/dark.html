Tor hidden service and static-site deployment — 2023

Project context

In October 2023, I deployed a small personal website on the dark web using a Tor hidden service. The purpose was not to publish sensitive content, but to experiment with the infrastructure: understand how a .onion service is exposed, how it connects to a conventional Nginx server and what the anonymity implications are.

Everything was configured manually from the command line. All screenshots were later kept offline for technical and responsible archiving, with no active links or redirects.

1. Tor service & .onion address

I configured and started Tor, checked its service state and retrieved the generated onion hostname from the hidden-service directory.

2. Nginx behind Tor

Nginx was used as the local HTTP server. Tor forwarded traffic from the hidden service to the local Nginx port, separating the web server from the anonymity layer.

3. Minimal static website

The website itself was deliberately minimal: a static HTML page edited directly on the host, without a framework or site generator. This kept the focus on infrastructure, service exposure, logging and attack surface.

4. What I learned

The project gave me a concrete understanding of Tor hidden services, the Tor ↔ Nginx ↔ static-site network chain and the anonymity considerations on the server side. It was a purely educational project and did not host illegal content.
