StegaGuard

Local steganography and Unicode analysis in URLs

Overview

StegaGuard is a small tool I developed to inspect URLs for invisible characters, Unicode homographs and mixed scripts that can be used to mislead users. The objective is not to claim perfect detection, but to experiment with a security area where very small character-level differences matter.

Local execution

StegaGuard runs entirely locally: analyzed URLs are never sent to a remote service, and the application can be tested without a backend deployment.

How it works

  • Invisible characters such as zero-width spaces, separators and controls.
  • Unicode homographs: visually similar letters from different alphabets.
  • Mixed scripts such as Latin, Greek and Cyrillic.
  • Unusual symbols in otherwise conventional URLs.

When suspicious behavior is found, the interface raises either a warning or an explicit alert to encourage the user to inspect the link before clicking.

Interpreting the results

The current test page displays a 33% precision score because warnings are counted neither as full successes nor as failures. In the test set documented by the project, no dangerous URL was missed and all suspicious characters were detected. The warnings represent gray areas rather than undetected cases.

What I learned

This project deepened my understanding of homoglyph attacks, invisible characters and Unicode manipulation in URLs. It also gave me practical experience with local analysis, simple interfaces and communicating security results clearly to users.
